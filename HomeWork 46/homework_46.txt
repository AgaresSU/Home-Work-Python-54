1. Студенты какой кафедры и факультета сдавали социологию.
SELECT DISTINCT g.Kafedra, k.Decanat
FROM Student s, G g, Kafedra k, Exzamen e
WHERE s."Group" = g."Group"
      AND g.Kafedra = k.Kafedra
      AND s.ID_St = e.Id_St
      AND e.Predmet = "Социология"

2. Выведите кафедры, список студентов, список студентов в алфавитном порядке.
SELECT g.Kafedra, s.FIO
FROM Student s, G g
WHERE s."Group" = g."Group"
ORDER BY g.Kafedra, s.FIO

3. Вывести номера зачеток только студентов физико-технического факультета.
SELECT z.N_Z
FROM Zachetki z, Student s, G g, Kafedra k
WHERE z.Id_Studenta = s.ID_St
      AND s."Group" = g."Group"
      AND g.Kafedra = k.Kafedra
      AND k.Decanat = "Физико-технический"

4. Выведите студентов физико-технического факультета, сдавших иностранный язык на 5.
SELECT s.FIO
FROM Student s, G g, Kafedra k, Exzamen e
WHERE s."Group" = g."Group"
      AND g.Kafedra = k.Kafedra
      AND s.ID_St = e.Id_St
      AND k.Decanat = "Физико-технический"
      AND e.Predmet = "Иностр. язык"
      AND e.Ball = 5

5. Подсчитать сколько различных предметов сдавалось в сессию.
SELECT COUNT(DISTINCT Predmet) AS "Количество предметов"
FROM Exzamen

6. Напишите запрос, который выводит средний балл по экзаменам Васильевой.
SELECT AVG(e.Ball) AS "Средний балл"
FROM Student s, Exzamen e
WHERE s.ID_St = e.Id_St AND s.FIO LIKE "Васильева%"

7. Определите сколько человек учится на каждой специальности.
SELECT Special, COUNT(*) AS "Количество студентов"
FROM Student
GROUP BY Special

8. Напишите запрос, который покажет все группы физико-технического факультета.
SELECT g."Group"
FROM G g, Kafedra k
WHERE g.Kafedra = k.Kafedra AND k.Decanat = "Физико-технический"

9. Вывести список фамилий студентов получивших 5 баллов по дифференциальным уравнениям.
SELECT s.FIO
FROM Student s, Exzamen e
WHERE s.ID_St = e.Id_St
      AND e.Predmet = "Дифференциальные уравнения"
      AND e.Ball = 5

10. Напишите запрос, который покажет, сколько экзаменов сдавал Шутов.
SELECT COUNT(*) AS "Количество экзаменов"
FROM Student s, Exzamen e
WHERE s.ID_St = e.Id_St AND s.FIO LIKE "Шутов%"

11. Выведите название кафедры студентов, не сдавших хотя бы один экзамен.
SELECT DISTINCT g.Kafedra
FROM Student s, G g, Exzamen e
WHERE s."Group" = g."Group"
      AND s.ID_St = e.Id_St
      AND e.Ball IS NULL

12. Подсчитать количество кафедр на каждом факультете.
SELECT Decanat, COUNT(Kafedra) AS "Количество кафедр"
FROM Kafedra
GROUP BY Decanat

13. Подсчитать количество пятерок на физико-математическом факультете.
SELECT COUNT(*) AS "Количество пятерок"
FROM Student s, G g, Kafedra k, Exzamen e
WHERE s."Group" = g."Group"
      AND g.Kafedra = k.Kafedra
      AND s.ID_St = e.Id_St
      AND k.Decanat = "Физико-математический"
      AND e.Ball = 5

14. Определите номера зачетных книжек группы ФТ151.
SELECT z.N_Z
FROM Zachetki z, Student s
WHERE z.Id_Studenta = s.ID_St AND s."Group" = "ФТ151"

15. Выведите перечень специальностей физико-математического факультета.
SELECT DISTINCT s.Special
FROM Student s, G g, Kafedra k
WHERE s."Group" = g."Group"
      AND g.Kafedra = k.Kafedra
      AND k.Decanat = "Физико-математический"
