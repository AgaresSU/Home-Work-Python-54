1. Вывести данные о товаре в алфавитном порядке.
SELECT *
FROM SallerGoods
ORDER BY Goods

2. Вывести посредников, поставляющих товар для фирмы.
SELECT *
FROM Seller
WHERE Status = "посредник"

3. На какую сумму было всего куплено каждого товара фирмой.
SELECT Goods, SUM(CostUnit * Count) AS "Сумма закупки"
FROM SallerGoods
GROUP BY Goods

4. Определить какой товар был куплен у посредников.
SELECT sg.Goods, s.Seller, s.Status
FROM SallerGoods sg, Seller s
WHERE sg.INNSeller = s.INNSeller AND s.Status = "посредник"

5. Написать запрос, который выводит название товара и прибыль, полученную от его продажи.
SELECT sg.Goods, SUM((cg.CostUnit - sg.CostUnit) * cg.Count) AS "Прибыль"
FROM SallerGoods sg, ClientGoods cg
WHERE sg.ID = cg.ID
GROUP BY sg.Goods

6. Определите какие клиенты не покупали подсолнечное масло.
SELECT *
FROM Client
WHERE INNClient NOT IN (
    SELECT cg.INNClient
    FROM ClientGoods cg, SallerGoods sg
    WHERE cg.ID = sg.ID AND sg.Goods = "масло подсолнечное"
)

7. Показать код и наименование товара, купленного посредниками.
SELECT sg.ID, sg.Goods
FROM SallerGoods sg, ClientGoods cg, Client c
WHERE sg.ID = cg.ID AND cg.INNClient = c.INNClient AND c.Status = "посредник"

8. Вывести список клиентов и сумму прибыли за каждый товар, полученную от продажи черного перца.
SELECT c.Client, sg.Goods, (cg.CostUnit - sg.CostUnit) * cg.Count AS "Прибыль"
FROM Client c, ClientGoods cg, SallerGoods sg
WHERE c.INNClient = cg.INNClient AND cg.ID = sg.ID AND sg.Goods LIKE "Перец черный%"

9. Выведите список товаров в обратном порядке, если товар куплен у производителя и продан в кафе.
SELECT sg.Goods
FROM SallerGoods sg, Seller s, ClientGoods cg, Client c
WHERE sg.INNSeller = s.INNSeller
      AND sg.ID = cg.ID
      AND cg.INNClient = c.INNClient
      AND s.Status LIKE "производит%"
      AND c.Status = "кафе"
ORDER BY sg.Goods DESC
