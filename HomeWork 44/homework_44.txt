1. Определите для какого товара код поставщика не определен. Полностью вся таблица, переименованные атрибуты.
SELECT ID AS "Код товара",
       Produce AS "Товар",
       Material AS "Материал",
       Color AS "Цвет",
       Size AS "Размер",
       Country AS "Страна",
       ID_salespeople AS "Код поставщика",
       Price AS "Цена",
       Count AS "Количество",
       REM AS "Описание"
FROM Ware
WHERE ID_salespeople IS NULL

2. Определить все товары, которые производятся в России (марка, код товара, страна).

FROM Ware

9. Вывести весь товар, который поставляет продавец с кодом 2065 из России.
SELECT *
FROM Ware
WHERE ID_salespeople = 2065 AND Country = "Россия"

10. Вывести товар, цена за который находится в диапазоне от 200 до 345.
SELECT *
FROM Ware
WHERE Price BETWEEN 200 AND 345

11. Определите все сумки из кожи с размером не менее 40х30х5.
SELECT *
FROM Ware
WHERE Material = "кожа" AND (Size LIKE "40x30%" OR Size LIKE "41x30%" OR Size LIKE "42x30%")

12. Написать запрос, который выводит все сумки и коды их поставщиков, если товара меньше чем на 1200.
SELECT Produce, ID_salespeople, Price * Count AS "Сумма товара"
FROM Ware
WHERE Price * Count < 1200

13. Написать запрос, который заменит код поставщика на 2000, если на складе хранится товара менее чем на 500.
UPDATE Ware
SET ID_salespeople = 2000
WHERE Count < 500

14. Вывести все кожаные сумки, количество которых менее 5 шт. и общая сумма товара не превышает 450.
SELECT *
FROM Ware
WHERE Material = "кожа" AND Count < 5 AND Price * Count <= 450

15. Напишите запрос, который выведет все нейлоновые сумки цена на которые не превышает 250.
SELECT *
FROM Ware
WHERE Material = "нейлон" AND Price <= 250

16. Замените материал нейлон на брезент, если сумка стоит менее 200.

19. Напишите запрос, который покажет все сумки с размером более 15 дюймов.
SELECT *
FROM Ware

20. Напишите запрос, который покажет всех поставщиков сумок не черного цвета.
SELECT DISTINCT ID_salespeople
FROM Ware
WHERE Color <> "ч" AND ID_salespeople IS NOT NULL

21. Замените материал полиэстер у сумок китайского производства на нейлон.
UPDATE Ware
SET Material = "нейлон"
WHERE Material = "полиэстер" AND Country = "Китай"

22. В записях с кодом товара: 1015, 1041, 1032, 1010 материал нейлон заменить на полиэстер если страна-производитель Китай.
UPDATE Ware
SET Material = "полиэстер"
WHERE ID IN (1015, 1041, 1032, 1010) AND Material = "нейлон" AND Country = "Китай"
